# Real-Time Systems: WebSockets & WebRTC

Modern web applications require instantaneous user feedback, whether through live collaboration cursors, chat notifications, or direct peer-to-peer video streams.

## Architecture Highlights

- **Socket.io Signaling:** Managing active room states, user presence, and fallback transports.
- **WebRTC Peer Connection:** Establishing direct audio/video data channels with minimal server relay overhead.
- **Redis Pub/Sub:** Scaling WebSocket connections across multiple Node server instances seamlessly.
